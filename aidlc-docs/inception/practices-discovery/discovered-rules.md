# Discovered Rules — LidarApp

Hard constraints the owner selected in the Practices Discovery interview, 2026-11-10.

## Mandated

ALWAYS make new behaviour visible in the app's built-in diagnostics, because there is no Mac to debug from
ALWAYS explain non-obvious code in plain language, because the owner relies on AI-written code
ALWAYS provide an on-device checklist with any delivery that changes sensor-dependent behaviour

## Forbidden

NEVER commit signing keys, certificates or credentials; the repository is public
NEVER add a dependency or service that costs money or requires an account or sign-up
NEVER commit directly to main after the initial commit
